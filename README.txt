PUBLISH WITH GITHUB PAGES (FREE)
1. Create/sign into GitHub. Choose a username, ideally hanapetals if available.
2. Create a public repository called <your-username>.github.io
3. Upload the CONTENTS of this folder, not the ZIP itself (index.html must be at root).
4. In repository Settings > Pages, set Source: Deploy from a branch, main, /(root), Save.
5. Visit https://<your-username>.github.io/ when deployment completes.
If instead the repository is called hana-petals-website, the URL is https://<your-username>.github.io/hana-petals-website/

Keep this website local until you're comfortable with the contents being public.
